// Common Questions

Answers before you ask.

Will my account get banned?

Honest answer: automated sharing is against Poshmark's terms of service. That said, we run conservatively — twice a day, ~600 shares, with randomized 3–8 second delays in a real browser. That's well below Poshmark's "share jail" threshold and looks like normal seller activity. We've been running this exact setup on a real seller's account for months without issue. Risk is never zero, and you accept that when you sign up. If Poshmark ever takes action against your account, we're not liable — but in practice it's extremely rare for active sellers using realistic pacing.

How do you handle my Poshmark password?

You send it once over an encrypted channel (Signal, 1Password share, or similar). It lives in an encrypted credentials file on our private server, accessible only to us. Never in cloud storage. Never on a web dashboard. After the first login, we store a session token so we don't have to use the password on every run. You can change your password any time and just send us the new one.

What if Poshmark changes their app and it breaks?

That's our problem, not yours. We monitor every session — if Poshmark changes a button or page layout, we fix it on our end. You don't install or update anything.

Why $49 when other bots are $25?

Because $25 bots make you install software, keep your computer on, learn the tool, and troubleshoot when it breaks. We do all of that for you. If you're comfortable being your own IT department, save the $24 and go that route. If you'd rather just have it handled, that's what you're paying for.

Can I cancel anytime?

Yes. Email us and we shut it down the same day. No annual contract, no cancellation fee. You only pay for the months you use.

Do you handle follows, offers, or relists?

Right now: closet sharing and party shares only. If there's demand we'll add follow/unfollow and offer-to-likers in a higher tier later. Tell us what you'd want on the discovery call.
